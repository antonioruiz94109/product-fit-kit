# Is this category a fit?

Score each test **pass**, **partial**, or **fail** using manufacturer pages as evidence. Any fail on tests 1–3 means **do not build**. Investigate partials before expanding research.

1. **Published:** the brand prints the specification on its own page.
2. **Objective:** it is a number, unit or yes/no fact, rather than a subjective rating.
3. **Comparable:** brands measure it the same way. A shared unit alone is not enough.
4. **Decisive:** buyers actually narrow their choices using it.
5. **Bounded:** roughly 15–30 models cover most of the relevant market.
6. **Slow churn:** products refresh annually or less frequently.
7. **Low risk:** an incorrect value causes inconvenience, not harm.

Poor-fit signals include taste-driven decisions, brand-specific test methods, sprawling size/color/SKU combinations, safety-critical choices, and categories dominated by changing prices.

Run `prompts/fit-test.md` with a browsing-capable AI. Ask it for 3–5 manufacturer pages supporting its assessment. Read those pages yourself. A plausible explanation without evidence is not a pass.

The example configs are starting points, not proof that their categories pass. A good category can still contain a bad filter: drop or demote that field before collecting more products.
